# 단디메카 Word 표준 포맷 플러그인

단디메카의 기술보고서, 설계 사양서, 수행계획서, URS 및 검증·인수 문서를 동일한 Word 디자인과 작성 규칙으로 생성하는 공유용 Codex 플러그인입니다.

## 포함 항목

- `artifact-template-word` 문서 템플릿 스킬
- 단디메카 Word 표준 포맷 기준본 v1.10
- 표지·문단·번호·표·그림·강조박스·상태 색상 규칙
- Pretendard Regular/Bold 글꼴이 포함된 기준 DOCX
- 템플릿 미리보기 이미지

## 사용 방법

플러그인을 설치한 뒤 새 Codex 작업에서 `$artifact-template-word`를 태그하고 작성할 문서를 설명합니다.

예시: `$artifact-template-word 고객 제출용 장비 개발 URS를 작성해줘.`

## 버전

- 플러그인: 1.0.0
- Word 포맷: 1.10
