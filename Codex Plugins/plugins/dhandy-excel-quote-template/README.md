# 단디메카 Excel 견적서 표준 포맷 플러그인

단디메카의 장비 개발 견적서를 동일한 Excel 디자인과 산출 규칙으로 작성하는 공용 Codex 플러그인입니다.

## 포함 항목

- `artifact-template-dhandy` 견적서 템플릿 스킬
- 3개 시트로 구성된 Excel 기준본
- 표지와 상세 견적의 A4 세로 인쇄 규격
- 고객 제출용 기준 PDF와 템플릿 미리보기
- 수식, 견적 단위 조정, 협의 할인, VAT 및 인건비 기준표 작성 규칙
- 고객 PDF에는 1·2번 시트만 포함하고 내부 인건비 기준표는 제외하는 규칙

## 사용 방법

플러그인을 설치한 뒤 새 Codex 작업에서 `$artifact-template-dhandy`를 태그하고 견적 대상, 목표 금액, 수행 기간과 필요한 사양을 설명합니다.

예시: `$artifact-template-dhandy 수행계획서를 기준으로 총액 7억원의 장비 개발 견적서와 고객 제출용 PDF를 작성해줘.`

## 편집 환경

- Excel 기준본의 글꼴은 Pretendard입니다. 동일한 화면과 인쇄 결과를 위해 편집 컴퓨터에도 Pretendard 설치를 권장합니다.
- 결과물은 편집 가능한 `.xlsx`와 1·2번 시트만 포함한 고객 제출용 `.pdf`를 함께 생성합니다.
- 기준 원본은 복제해 사용하며 플러그인 내부 파일을 프로젝트 결과물로 덮어쓰지 않습니다.
